# 🌐 Web-based 3D Digital Twin Projects

웹 브라우저에서 실시간으로 동작하는 **3D 디지털 트윈(Digital Twin) 시뮬레이션** 프로젝트입니다. 순수 HTML, CSS, JavaScript와 [Three.js](https://threejs.org/) 라이브러리를 활용하여 구축되었으며, 외부 모델 파일(GLTF/OBJ 등) 다운로드 없이 프로시저럴(Procedural) 방식으로 3D 객체를 생성하여 가볍고 빠르게 실행됩니다.

## 📂 프로젝트 구성

본 저장소는 다음 두 가지 디지털 트윈 환경을 포함하고 있습니다.

### 1. 🏫 스마트 교실 디지털 트윈 (Smart Classroom)
**파일명:** `smart_classroom_camera_stable.html`

실사풍으로 구현된 현대적인 학교 교실의 3D 공간과 가상 IoT 환경을 모니터링하고 제어할 수 있는 시뮬레이션입니다.

* **주요 기능:**
  * **IoT 센서 시뮬레이션:** 실내 온도, CO₂ 농도, 교실 조도, 재실 인원 등을 실시간 시계열 그래프로 모니터링
  * **환경 설비 제어:** 자연광 유입량, 에어컨/환기 장치, LED 조명, 블라인드 개방 정도를 슬라이더로 조절하여 3D 장면에 즉각 반영
  * **시나리오 프리셋:** 수업 중, 쉬는 시간, 집중 환기, 야간 소등 등 상황에 맞는 최적화된 환경 원클릭 설정
  * **안정적인 뷰포트:** 벽면 절개 뷰(Cutaway) 및 카메라 이동 제한 기능이 적용된 5가지 다중 시점(교실 전체, 학생, 칠판, 창가, 평면 조망) 지원

### 2. 🚌 전기 시내버스 조립 공장 (EV Bus Assembly Factory)
**파일명:** `ThreeJS_korean_bus.html`

한국형 저상 전기 시내버스의 제조 공정을 8단계로 나누어 시각화한 가상 스마트 팩토리 시뮬레이션입니다.

* **주요 기능:**
  * **가상 조립 공정:** 하부 프레임, 차축, 배터리, 차체 골격부터 품질 검사까지 8단계의 조립 공정을 수동/자동 재생
  * **디지털 관제 UI:** 공정 진행률, 완료 모듈, 작업 상태(대기/진행/완료)를 시각적으로 보여주는 상태 패널
  * **정밀 관찰 모드:**
    * `X-RAY 뷰`: 외판을 반투명하게 처리하여 내부 구조(배터리, 뼈대 등) 확인
    * `분해 보기(Explode)`: 각 부품 모듈을 공간적으로 분리하여 조립 위치 및 구조 파악
  * **상호작용:** 조립된 부품 클릭 시 상세 정보 제공, 도어 개폐 애니메이션, 버스 외판 색상 변경(파랑, 초록, 빨강, 노랑)

## 🛠 기술 스택
* **Core:** HTML5, CSS3, Vanilla JavaScript (ES Modules)
* **3D Graphics:** [Three.js (r164, r180)](https://threejs.org/)
* **Controls:** OrbitControls (Three.js Addon)

## 🚀 실행 방법
이 프로젝트는 복잡한 빌드 과정이나 Node.js 서버 구성이 필요하지 않습니다.

1. 이 저장소를 클론(Clone)하거나 ZIP 파일로 다운로드합니다.
2. 실행하고자 하는 HTML 파일(`smart_classroom_camera_stable.html` 또는 `ThreeJS_korean_bus.html`)을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari 등)에서 엽니다.
3. *주의사항: Three.js 라이브러리를 외부 CDN에서 동적으로 불러오므로 **인터넷 연결이 필수적**입니다.*

## 📝 라이선스
이 프로젝트는 교육 및 포트폴리오 목적으로 작성된 개념 증명(PoC) 모델입니다. (실제 센서 데이터나 제조사의 실제 CAD 도면을 반영하지 않은 가상 데이터입니다.)
